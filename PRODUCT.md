## Platform

web

## Stack

delegated: static HTML, CSS, and JavaScript for the first MVP so the lab task board can run locally without setup complexity. A backend, auth provider, and database remain open decisions for a shared production version.

They use it daily on personal computer browsers and occasionally on phones to check progress, update tasks, and prepare for meetings.

## Product Purpose

The product organizes linguistics lab projects, tasks, plans, attachments, discussion, meetings, and a lightweight community exchange in one editable webpage. Its primary success measures are fewer forgotten tasks, more transparent project status, and a livelier lab knowledge flow.

Default project areas include ITF, Emotion Recognition, Gesture, AI Conference, Appraisal Theory, English focus, Robot interaction, Dissertation, Multimodal assistive technology and AI, and Science Robotics. The current seed task list includes concise Aug 31 work for Skye Xi CHEN, Ting ZHANG, Yanyu YANG, and Fang ZHOU.

## Positioning

Unlike a generic project management template, the product centers the lab's two daily questions: which project is moving, and what does each person need to do next?

## Operating Context

The application supports daily task checks, meeting preparation, weekly priority planning, deadline reviews, quick mobile status updates, two standing Zoom meetings, creator attribution for Skye Xi CHEN, and informal exchange of linguistics questions, ideas, methods, code snippets, Praat/R code, RStudio palettes, links, images, videos, audio notes, files, and saved references. The first version needs refresh-based collaboration, not real-time multi-user sync.

## Capabilities and Constraints

Confirmed capabilities include project and people views, tasks with multiple participants, editable task status and priority, comments, file attachment records, checklists, project progress summaries, right-click project editing/status changes/deletion/completion, right-click task opening/status changes/deletion from task cards, manual project progress adjustment, adding and deleting tasks from a member's people view, right-click adding and deleting members by role in the People tab, a Meeting tab for Lab meeting Wednesday 17:00 HK Time and RA meeting Friday 14:00 HK Time Zoom links, clearer spacing between project tasks, and a Community tab for publishing, commenting on, filtering, and visually distinguishing posts with text, links, images, videos, audio, uploaded files, code, favorites, method notes, palette shares, and the lab official members page. Real authentication, database persistence, reminders, calendar integration, and real-time collaboration are future decisions.

## Brand Commitments

The product is named LabFlow. The interface should feel simple, clear, calm, logical, high-quality, and warm, using a pale beige background with black iconography and text. Its mark is a square black LF monogram above a bar-chart signal. It should avoid clutter while still leaving room for lively community exchange.

## Evidence on Hand

No real lab data, files, names, or assets have been provided. The MVP uses clearly synthetic sample content that should be replaced before real lab use.

## Product Principles

- Make priority and ownership visible within seconds.
- Keep project progress transparent without forcing heavy reporting.
- Encourage daily updates with lightweight controls and friendly feedback.
- Support both project-first and people-first thinking.
- Stay calm and structured while leaving room for momentum and expectation.
